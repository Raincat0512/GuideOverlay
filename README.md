# 攻略悬浮窗 GuideOverlay

把攻略图、地图、参考文档**浮在游戏画面上**：平时完全鼠标穿透、不挡点击不抢焦点，按住门控键才可操作。

[English](README.en.md) · [使用说明](使用说明.md)

当前版本：**1.1.0**（exe 右键「属性 → 详细信息」可查）

## 特性

- **单文件 C# 5 + WinForms**：整个程序只有一个 `Program.cs`，零第三方依赖，用 Windows 自带的 .NET Framework 编译器即可构建（`build.bat`，不需要 Visual Studio / SDK / NuGet）。
- **默认鼠标穿透**：窗口用 `WS_EX_TRANSPARENT | WS_EX_NOACTIVATE` 实现，点击、滚轮、拖动直接落到下面的游戏里，窗口不抢焦点。
- **门控式交互**：按住门控键（默认 `Alt`，可在设置面板改为 `Ctrl`/`Shift`）才可拖动、缩放、翻页、调整窗口；松开立即恢复穿透。也可用 `Ctrl+Alt+T` 锁定交互。
- **图片库**：扫描文件夹轮播图片，支持自动刷新（保留当前阅读位置与缩放）、自然排序、长图模式（超长图自动切片/滚动查看）。
- **完整设置面板**：窗口（位置/大小/透明度/置顶/门控键）、显示、缩放、热键、图片、诊断六个分区；18 个热键都可改键或禁用。
- **右键菜单 + 顶部工具条**：翻页、适应窗口、锁图、缩放、旋转翻转、长图开关、设置、隐藏等。
- **不做危险操作**：不注入进程、不 Hook、不模拟键鼠、不联网。
- **自带自测**：`GuideOverlay.exe --selftest` 跑 577 条断言并输出 4 张截图，退出码 0/1，可用于回归。

## 运行环境

- Windows 7 SP1 及以上（在 Windows 10 / 11 上测过）
- .NET Framework 4.x（Windows 10/11 自带 4.8）
- 不需要管理员权限；不需要联网

## 快速开始

1. 从 [Releases](../../releases) 下载发布包（内含预编译 `GuideOverlay.exe`），或克隆仓库后直接使用仓库里的 exe，也可以按下面的「从源码构建」自行编译。
2. 把整个文件夹放到任意位置（**不要**在压缩包里直接双击 exe，见「已知限制」）。
3. 双击 `GuideOverlay.exe`，窗口出现在屏幕一侧。
4. 按住 `Alt` 拖动 / 缩放 / 翻页；松开鼠标，窗口立刻恢复穿透。
5. 首次运行有约 20 秒的引导提示条，按过门控键或超时后自动结束。

## 默认热键（节选）

| 操作 | 默认热键 |
| --- | --- |
| 门控键（按住可操作） | `Alt`（可改为 `Ctrl` / `Shift`） |
| 锁定 / 取消锁定交互 | `Ctrl+Alt+T` |
| 隐藏 / 呼出窗口 | `Ctrl+Alt+G` |
| 上一张 / 下一张 | `Ctrl+Alt+←` / `Ctrl+Alt+→` |
| 缩放（光标位置为锚点） | 按住门控键 + 滚轮 |
| 平移图片 | 按住门控键 + 左键拖动 |
| 回到适应窗口 | 按住门控键 + 双击左键 |
| 打开设置面板 | 按住门控键 + 点工具条「设置…」 |

完整热键表与说明见 [使用说明](使用说明.md)。

## 从源码构建

需要 Windows 自带的 `csc.exe`（`%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\`，32 位系统回退 `Framework`）。

```bat
build.bat            :: 编译出 GuideOverlay.exe（失败不会删掉旧 exe）
GuideOverlay.exe --selftest
```

> `build.bat` 以 GBK(936) 编码保存（内含中文提示），请勿用 UTF-8 工具另存，否则失败提示会乱码。

`build.bat` 先把源码编译到 `obj\GuideOverlay.exe`，成功后才替换根目录的 exe；编译错误、exe 被占用、找不到 csc 时都会给出中文提示并保留旧 exe。

## 隐私与权限

- 不联网、不收集/上传任何数据、不写注册表、不留后台服务。
- 配置只写在程序同目录的 `settings.ini`（首次运行自动生成；保存时生成 `settings.ini.bak` 备份）。
- 图片目录只读扫描，不会修改或删除你的图片。
- 程序**没有数字签名**，首次运行可能被 SmartScreen / 杀软拦，处理方式见 [使用说明](使用说明.md)。

## 已知限制

- 从聊天软件/网页直接双击压缩包内的 exe（以低权限宿主启动）时读不到键盘，门控键会失效；请先解压到本地，再从资源管理器启动。
- `--selftest` 的 PNG 只能验证绘制结果，无法验证窗口透明度（第 3、4 张截图刻意保持相同，属预期）。
- 仅支持 Windows。
